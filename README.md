## Projeto Análise Estatística
Este projeto analisa o comportamento de consumo de clientes da empresa Megaline para identificar qual dos planos pré-pagos, Surf ou Ultimate, é o mais rentável. A análise foca-se em padrões de chamadas, mensagens e uso de dados de internet durante o ano de 2018.

## Tecnlogias Usadas
Python

Pandas: Manipulação de dados e merges complexos.

NumPy: Operações lógicas e matemáticas.

Matplotlib / Seaborn: Visualização de tendências e distribuições.

SciPy (stats): Testes de hipóteses.
